# Breakfast Club — Knowledge Base

How to use this with Claude Code:

1. Create an empty folder/repo and copy this whole folder in (`CLAUDE.md` at the root, `docs/` beside it).
2. Check `docs/open-questions.md` — answer the remaining items or accept the defaults.
3. Open Claude Code in that folder. It reads `CLAUDE.md` automatically.
4. Prompt one milestone at a time:
   > Read CLAUDE.md and the docs folder, then implement Milestone 0 from docs/build-plan.md.
5. After each milestone, test it, commit, then move to the next.

When requirements change, update the doc first, then ask Claude Code to bring the code in line.
